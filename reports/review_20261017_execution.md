## 模拟实际业务的验收设计

输入固定在 `tests/fixtures/review_20261017_poc.json`，不依赖真实客户资料、随机数或外部行情。所有价格、预测、设备参数均为测试假设，不代表市场测算或收益承诺。通过真实 API 为三个场景创建、测试并发布模型，再正式提交任务。全部使用真实 HiGHS。

## 浏览器和部署验证

两条 Playwright + Chrome 旅程均使用真实后端：

1. 克隆经济调度模型，修改名称，侧栏跳转被保护；继续编辑保留字段，保存遇到 503 时仍停留；恢复后真实测试并发布。
2. 在线调试先输入错误 JSON 并修正，提交真实 HiGHS 任务，测试环境仅增加 35 秒等待；刷新恢复同一 task_id，任务查询 503 后重试恢复，最后进入真实结果报告。全过程只产生 1 次求解提交。

Docker 从仓库 Dockerfile 构建，采用官方默认启动入口、独立测试卷和合成访问令牌。镜像包含 Python 3.12.15、HiGHS 1.15.1、Ipopt 3.14.20。官方 NLP 水电样例返回 optimal，目标约 `15000.00000245`，独立功率关系最大残差 `1.36e-7`，保留 `local_optimum_warning=true`。更换容器主机名、保留卷后，下线状态和加密测试 Key 均恢复，带 token 健康检查通过。

本机 Python 没有 Ipopt，所以本机 5 项相关测试跳过；最终 Docker 镜像中另外运行了 9 项 NLP 相关测试，全部通过，覆盖这些环境跳过项。没有连接真实 LLM 供应商，Agent 仅完成确定性协议、工具接线和状态回归；目标 LLM 的真实工具调用旅程仍需实际服务接入。
