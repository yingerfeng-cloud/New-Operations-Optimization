## 实际行为与兼容性

- 自动保存更新同一草稿，首次保存后地址定位到该模型 ID。允许已填集合及部分参数、尚无完整目标约束的半成品；发布继续执行完整校验和真实求解测试。保存串行且相同内容共用请求，避免自动保存和手动操作创建重复资产。
- 保存失败时停止自动重试并提供手动重试。本机最多保留 20 个工作区恢复副本，包括未提交内容、步骤和小节；模型中心可继续编辑。浏览器清理存储、隐私模式限制或存储空间不足会影响本机副本，界面显示备份失败状态。
- 服务端保存和返回开发态支持可选内容 hash 前置条件；旧客户端仍可调用。新版工作台遇到另一位置已保存的内容返回冲突，并保留本机副本，避免静默覆盖。
- 模型测试记录稳定的模型 ID、task_id、提交标识和所测内容。刷新或短暂断网后继续读取同一任务。未收到提交响应时可核对服务端任务指针，避免重复创建有效任务。函数更新候选使用同一工作区恢复机制。
- 恢复 SUCCESS 后重新获取当前模型，核对任务所测 hash、模型内容 hash、tested_model_id 和求解通过证据。测试后编辑或更换依赖仍须重测。进程重启中的运行任务按现有规则标为 INTERRUPTED，不宣称能够续算求解器内部状态。
- 模型服务示例使用 model_code 跟随正式版本；固定 ID 调试仍明确固定版本。函数候选从工作台发布也执行正式版本冲突检查。

本机恢复数据是编辑辅助，不能授予发布能力；现有严格 PWL、统一时长、V3 权威任务及发布门槛均保留。严格一维函数启用时，即使水电出力关系选择线性，整体仍含分段二进制变量，前端诊断及原相关断言据实际 MILP 行为对齐。
