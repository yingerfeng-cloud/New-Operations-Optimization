## 产品问题与复现边界

1. **一维公式预估计数。**time=[0,1] 时公式弹窗预估曾显示4条 / 4项；实际业务变量只有两个时点。主手册将数学意图与界面估算分开，未把预估当作正确展开证据。
2. **组件默认值为文本。**参数接口填 [15,25]、2、0.5 后，执行校验出现 `'<=' not supported between instances of 'VarData' and 'str'`。仅清空仍失败；删除草稿接口行后重建且不填默认 / 示例值，校验、发布成功。没有把错误建议中的“检查索引”直接当作根因。
3. **组件模型整体提交。**显式绑定 max_output→capacity_limit，三个数值参数在结构预览可见，页面发布前检查通过，真实测试提交仍422。重新打开草稿后再测仍复现。根因未完全定位；主手册明确停止发布并给出交接材料。
4. **Builder 转换不等于完整迁移。**复制已发布一维模型后切组件化，通用需求约束 / 费用目标仍可见且编译，但曲线测试没有按原业务意图执行。映射本身给出了与实际p一致的fee，仍不能通过整体验收。发布诊断另报组件目标为空。不得将这个案例写为“曲线教程端到端通过”。
5. **历史缺失不自动恢复。**派生资产丢失、历史环境重放、旧密文迁移等边界依据当前实现及已有项目报告写入，未声称本轮重新完成历史版本复现。新修复不能凭空恢复已丢历史资产。
