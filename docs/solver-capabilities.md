# 平台求解能力与独立后续需求

本批仅统一声明，没有增加求解器或开放新的问题类型。

| 问题类型 | 平台正式路径 | 边界 |
|---|---|---|
| LP | HiGHS | 实际后端安装并可用时执行 |
| MILP | HiGHS | 整数与二进制变量实际进入求解 |
| 连续 NLP | Ipopt | 需要可用的原生程序；保留局部最优提示 |
| 原生 QP | 未支持 | 能识别二次结构；路由明确拒绝，不推荐一个尚未接通的后端 |
| 原生 MIQP | 未支持 | 不能四舍五入连续解来替代整数二次求解 |
| 生产 MINLP | 未开放 | 仅保留识别与明确错误 |
| PWL / McCormick | 已有转换路径 | PWL 只对所声明的分段函数保持对应语义；对平滑二次函数的近似不是原生 QP。McCormick 是有明确边界的松弛。 |

接口 `GET /api/solvers/status` 返回每个适配器支持类型及未开放类型。配置页、模型诊断和求解进度使用同一边界；后端路由仍是最终门槛。

## 另行授权后实施的方案

连续凸 QP 优先限定为连续变量、二次目标、线性约束、可验证半正定 Hessian。需要二次项与交叉项、常数项、目标方向、边界与线性约束的完整传递，真实状态/超时/不可行语义、实际版本以及 API/页面结果链路验收。不能只增加支持列表。独立已知答案至少包括 `(x-1.3)^2` 的 x=1.3、目标 0，以及 `(x+y-4)^2+(y-1)^2` 的 x=3,y=1、目标 0。

MIQP 必须独立选择真正支持整数二次模型的后端，再确认部署、授权、凸性与最优性证明范围。整数例 `(x-1.3)^2`、0≤x≤3 应为 x=1、目标 0.09，必须由实际整数二次求解证明；不采用连续解四舍五入或 PWL 近似充数。非凸 QP、二次约束、MINLP 都不随连续凸 QP 默认开放。

2026-10-21 核对的 [HiGHS 官方文档](https://ergo-code.github.io/HiGHS/dev/)说明底层支持半正定连续 QP，不支持带整数变量的 QP。这是底层软件的范围，不能视作本平台已完成适配。本文方案未执行，也没有取得新增后端或商业授权。
